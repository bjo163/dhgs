# DHGS Visual Identity — Foundation

Status: exploratory, pre-institutional. This is not a government seal.

## Design intent

DHGS should feel calm, precise, accountable, open, and human. The visual language should communicate balance and traceability without implying sacred authority or glorifying a leader.

> Design must clarify power, not glorify it.

## Concept

The initial mark is an abstract **balanced horizon**:

- circle: bounded authority / accountability;
- horizontal axis: Mizan / balance;
- central point: accountable decision point;
- rising upper arc: movement from darkness toward clarity;
- open negative space: review and correction remain possible.

The mark does not depict Allah, a prophet, a person, a national emblem, or a claimed sacred form.

## Initial palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#132033` | text, structural line, primary mark |
| Paper | `#F8F7F2` | quiet background |
| Balance | `#B8852F` | restrained emphasis, mark accent |
| Clarity | `#276C68` | constructive / informational accents |
| Danger | `#A33A3A` | critical status only |
| Focus | `#185ADB` | focus ring / interactive accessibility |

Status never relies on color alone.

## Logo variants

- `dhgs-mark.svg` — primary mark.
- `dhgs-lockup.svg` — mark + DHGS wordmark.
- `dhgs-mark-mono.svg` — monochrome.
- `favicon.svg` — compact browser/app mark.

The wordmark currently uses system typography for portability. A future brand typeface may be adopted only with licensing and accessibility review.

## Icon language

Use simple geometric 24×24 icons, restrained stroke weight, rounded joins, and visible labels for high-stakes functions. Icons never carry status alone.

## Imagery

Prefer documentary imagery only when provenance, permission, privacy, and context are known. Generated illustration must be labeled when it could be mistaken for documentary reality.

## Charts

Use truthful scales, source labels, units, periods, last-updated timestamps, uncertainty where material, and table alternatives for important public data.
