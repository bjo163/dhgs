# DHGS Design Foundation

This directory turns the Product Experience Plane in `BLUEPRINT.md` into design artifacts that can be implemented and tested.

## Canonical artifacts

- `tokens.json` — machine-readable visual tokens.
- `sitemap.md` — public and operations information architecture.
- `screen-map.md` — stable screen inventory and purpose.
- `wireframes.md` — low-fidelity page contracts and interaction patterns.
- `visual-identity.md` — brand, logo, icon, image, graph, and asset rules.
- `content-style.md` — plain-language and status-language standard.
- `asset-manifest.json` — initial governed asset registry.

## Design rule

> Design must clarify power, not glorify it.

Design artifacts do not create legal authority. High-stakes interactions remain subject to the governance requirements in `BLUEPRINT.md`.
