# Governed Images

Raster/photo assets belong here only when provenance, license/permission, privacy, consent where required, and intended use are known.

Rules:

- do not place case evidence here;
- strip unnecessary EXIF/location metadata before public delivery;
- do not expose victims or protected persons unnecessarily;
- do not present generated/synthetic imagery as documentary evidence;
- prefer AVIF/WebP delivery for web raster imagery where appropriate;
- record production assets in `design/asset-manifest.json`.

Evidence imagery remains under the Evidence lifecycle and provenance model, not this creative-asset directory.
